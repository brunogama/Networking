## Architecture Impact

### New Types

**HTTPMethodConfig**:
```swift
public struct HTTPMethodConfig: Sendable {
  let method: String
  let requiresBody: Bool
  let allowsVoidReturn: Bool

  static let get, post, put, patch, delete
}
```

**ArgumentExtractors**:
```swift
public enum ArgumentExtractors {
  static func extractPath(from:context:) -> String?
  static func extractBodyParameter(from:context:) -> String?
  static func extractQueryParameters(from:context:) -> [String]
  static func extractHeaders(from:context:) -> [String: String]
}
```

### Dependency Chain

## Key Decisions

1. **HTTPMethodConfig as Sendable value type**: Ensures thread-safe access in macro expansion context
2. **Static factory properties instead of initializers**: Provides discoverable API (`.get`, `.post`, etc.)
3. **ArgumentExtractors as enum (no cases)**: Prevents instantiation, pure namespace for static methods
4. **extractBodyParameter returns nil without error**: Caller (HTTP macro) decides error based on `HTTPMethodConfig.requiresBody`
5. **Extracted complexity helpers**: `parseHeaderDictionary` and `parseHeaderElement` keep main function under complexity limit
