   - Implement the 10-step workflow from research:

   Step 1: Validate function declaration
   ```swift
   guard let function = declaration.as(FunctionDeclSyntax.self) else {
     MacroHelpers.emitError(
       "@\(config.method) can only be applied to function declarations",
       node: node,
       context: context
     )
     return []
   }
   ```

   Step 2: Validate async throws
   ```swift
   try MacroHelpers.validateAsyncThrows(function: function, context: context)
   ```

   Step 3: Extract and validate path
   ```swift
   guard let path = ArgumentExtractors.extractPath(from: node, method: config.method, context: context) else {
     return []
   }
   try MacroHelpers.validatePathTemplate(path, context: context)
   ```

   Step 4: Detect syntax style
   ```swift
   let usesOldSyntax = function.usesOldMacroSyntax()
   let newBodyParam = function.detectBodyMacro()
   let newHeaders = function.detectHeadersMacro()
   ```

   Step 5: Check for syntax mixing
   ```swift
   if usesOldSyntax && (newBodyParam != nil || !newHeaders.isEmpty) {
     MacroHelpers.emitError(
       "Cannot mix old and new syntax for @\(config.method)",
       node: node,
       context: context
     )
     return []
   }
   ```

   Step 6: Emit deprecation warning for old syntax (if applicable)
   ```swift
   if usesOldSyntax {
     MacroHelpers.emitWarning(
       "Old syntax is deprecated. Use @Body and @Headers macros instead.",
       node: Syntax(node),
       context: context
     )
   }
   ```

   Step 7: Extract body parameter (if required by config)
   - Call private helper `extractBodyIfRequired()`
   - Return [] if body required but not found

   Step 8: Extract query parameters and headers
   ```swift
   let queryParams = ArgumentExtractors.extractQueryParameters(from: node, context: context)
   let headers = extractHeaders(node: node, newHeaders: newHeaders, context: context)
   ```

   Step 9: Validate parameters exist in function signature
   ```swift
   let functionParams = MacroHelpers.extractParameterNames(from: function)
   try MacroHelpers.validatePathParameters(path: path, functionParameters: functionParams, context: context)
   if !queryParams.isEmpty {
     try MacroHelpers.validateQueryParameters(queryParams, functionParameters: functionParams, context: context)
   }
   ```

   Step 10: Extract return type and generate implementation
   ```swift
   let returnType = extractAndNormalizeReturnType(function: function, context: context)
   guard let returnType = returnType else { return [] }

   return [generateImplementation(
     function: function,
     path: path,
     bodyParameter: bodyParam,
     queryParameters: queryParams,
     headers: headers,
     returnType: returnType
   )]
   ```

4. Private helper methods in the extension:
   - `extractBodyIfRequired()` - handles body extraction with config.requiresBody check
   - `extractHeaders()` - merges new and old syntax headers
   - `extractAndNormalizeReturnType()` - handles allowsVoidReturn normalization
   - `generateImplementation()` - delegates to InterceptorCodeGenerator
   - `findParentProtocol()` - traverses AST for interceptor detection
   - `generateBodyCode()` - generates body encoding
   - `generateHeaderCode()` - generates header additions
   - `generateQueryParameterCode()` - generates query parameter additions

Keep each private helper function under 30 lines. Total file should be 200-250 lines.
