<technical_notes>
## Macro Types

| Macro | Type | Role |
|-------|------|------|
| @API | PeerMacro | Generates implementation struct from protocol |
| @GET/POST/etc | PeerMacro | Generates method implementations |
| @Cacheable | AccessorMacro | Adds caching configuration accessor |
| @Measured | AccessorMacro | Adds timing instrumentation accessor |
| @Timeout | AccessorMacro | Adds timeout configuration accessor |
| @DefaultHeaders | AccessorMacro | Adds default headers accessor |
| @Body | AccessorMacro | Adds body binding accessor |
| @Headers | AccessorMacro | Adds headers binding accessor |
| @Interceptors | AccessorMacro | Adds interceptor chain accessor |

## Diagnostic Testing

MacroTesting supports diagnostic assertions:
```swift
assertMacro {
  """
  // source with error
  """
} diagnostics: {
  """
  // expected diagnostic output
  """
}
```

Diagnostic format uses Unicode box-drawing:
- `┬` for column pointer
- `╰─` for message
- Messages prefixed with severity (error:, warning:, note:)
</technical_notes>
