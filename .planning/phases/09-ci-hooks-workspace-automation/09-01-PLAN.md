**Jobs:**

1. **build-and-test** job with matrix strategy:
```yaml
strategy:
  fail-fast: true
  matrix:
    package:
      - MacroTemplateKit
      - NetworkingMacros
      - Networking
      - NetworkingWebSocket
      - NetworkingGraphQL
```

2. **Steps for each package:**
- Checkout with `actions/checkout@v4`
- Setup Swift with `swift-actions/setup-swift@v2` (swift-version: '6.0')
- Cache SPM dependencies with `actions/cache@v4`:
  - path: `Packages/${{ matrix.package }}/.build`, `~/.swiftpm`
  - key: `${{ runner.os }}-spm-${{ matrix.package }}-${{ hashFiles('Packages/${{ matrix.package }}/Package.swift') }}`
- Build with warnings-as-errors: `swift build --package-path Packages/${{ matrix.package }} -Xswiftc -warnings-as-errors`
- Detect tests: Check if `Packages/${{ matrix.package }}/Tests` directory exists
- Run tests (conditional): `swift test --package-path Packages/${{ matrix.package }}`

3. **Concurrency control:**
```yaml
concurrency:
  group: ci-${{ github.ref }}
  cancel-in-progress: true
```

4. **runs-on: macos-14** (required for Swift 6.0 and macros)

**Important:** Use `fail-fast: true` to stop all jobs on first failure.

**Changes to "Extract and Compare Symbols" step (line 71-122):**
Update jq command to consolidate symbols from all packages:
```bash
# Consolidate all package symbols into single baseline
for pkg in MacroTemplateKit NetworkingMacros Networking NetworkingWebSocket NetworkingGraphQL; do
  if [ -f ".build/symbol-graphs/$pkg/$pkg.symbols.json" ]; then
    jq -c --arg pkg "$pkg" '[
      .symbols[]? |
      select(.accessLevel == "public" or .accessLevel == "open") |
      select(.identifier.precise | contains("SYNTHESIZED") | not) |
      {
        package: $pkg,
        name: .names.title,
        kind: .kind.identifier,
        precise: .identifier.precise
      }
    ]' ".build/symbol-graphs/$pkg/$pkg.symbols.json"
  fi
done | jq -s 'add' > .cache/current-symbols.json
```
