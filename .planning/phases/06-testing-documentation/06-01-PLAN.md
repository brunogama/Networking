**CRITICAL IMPLEMENTATION NOTE**: SequentialMock is a STANDALONE test utility. It does NOT wrap MockNetworkClient (which uses first-fit matching internally). Instead, it provides its own response logic via MockURLProtocol.

Implementation requirements:

1. Create `SequentialMock` struct conforming to `Sendable`:
   - Private property `expectations: [(request: MockExpectation, response: MockResponse)]`
   - Private actor `CallTracker` with atomic call index counter
   - Public method to create a configured `URLSession` for testing

2. Implement initializer using existing `@MockRuleBuilder` or simple array:
   ```swift
   public init(@MockRuleBuilder _ content: () throws -> [MockRule]) throws
   ```
   - Store expectations in array order
   - Create MockURLProtocol handler that serves responses sequentially

3. Create internal `SequentialHandler` for MockURLProtocol:
   - Register with MockURLProtocol using unique request handler
   - Track current call index via actor
   - On each request:
     a. Get expectations[index]
     b. Validate request matches expectations[index].request
     c. If match: return expectations[index].response, increment index
     d. If mismatch: return error response with SequentialMockError details
   - If index >= expectations.count: return error for unexpected call

4. Define `SequentialMockError` enum with cases:
   - `.unexpectedCall(index: Int, request: HTTPRequest)`
   - `.requestMismatch(expected: MockExpectation, actual: HTTPRequest, atIndex: Int)`
   - `.unconsumedExpectations(remaining: Int)`

5. Provide `createSession() -> URLSession` method:
   - Returns URLSession configured with ephemeral config
   - MockURLProtocol registered as protocol class
   - Sequential handler installed

6. Add `verifyAllExpectationsConsumed() throws` method:
   - Check if all expectations were matched
   - Throw `.unconsumedExpectations(remaining: Int)` if not all consumed

Use actor for thread-safe call tracking (Swift 6 concurrency). Reuse existing MockExpectation matching logic from MockDSL.swift where applicable.
