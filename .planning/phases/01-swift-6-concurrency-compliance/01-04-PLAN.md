Output: Reentrancy-audited actors with documented patterns
</objective>

Fix pattern for token refresh:
```swift
actor TokenManager {
    private var refreshTask: Task<Token, Error>?

    func getValidToken() async throws -> Token {
        // Check if refresh in progress - join existing
        if let existing = refreshTask {
            return try await existing.value
        }

        // Check if current token valid
        if let token = currentToken, !token.isExpired {
            return token
        }

        // Start new refresh - store BEFORE await
        let task = Task { try await performRefresh() }
        refreshTask = task

        defer { refreshTask = nil }

        let newToken = try await task.value
        currentToken = newToken
        return newToken
    }
}
```

Key: Store task reference BEFORE awaiting, clean up in defer.

CachingMiddleware has medium reentrancy risk with cache get/set.

Audit checklist:
1. Check-then-act: Does it check cache, await network, then store?
2. Stale reads: Can cached value change during await?
3. Double fetch: Can same key be fetched multiple times?

Fix pattern for cache-aside:
```swift
actor CachingMiddleware {
    private var inFlightRequests: [CacheKey: Task<Response, Error>] = [:]

    func get(key: CacheKey) async throws -> Response {
        // Check cache first
        if let cached = cache[key], !cached.isExpired {
            return cached.response
        }

        // Check if request in flight - join existing
        if let existing = inFlightRequests[key] {
            return try await existing.value
        }

        // Start new request - store BEFORE await
        let task = Task { try await fetchFromNetwork(key) }
        inFlightRequests[key] = task

        defer { inFlightRequests[key] = nil }

        let response = try await task.value
        cache[key] = CacheEntry(response: response)
        return response
    }
}
```

        // Guard prevents concurrent connect
        guard state == .disconnected else {
            throw WebSocketError.invalidState
