  <files>Sources/Networking/CachingMiddleware.swift</files>
  <action>
AsyncSemaphore stores continuations in an array for later signal.

Audit checklist:
1. Every stored continuation must eventually be resumed
2. Handle actor deallocation (deinit cleanup)
3. Handle cancellation (Task.isCancelled check)

Fix pattern:
```swift
actor AsyncSemaphore {
    private var waiters: [CheckedContinuation<Void, Never>] = []

    func wait() async {
        await withTaskCancellationHandler {
            await withCheckedContinuation { continuation in
                // Check cancellation before storing
                if Task.isCancelled {
                    continuation.resume()
                    return
                }
                waiters.append(continuation)
            }
        } onCancel: {
            // Signal to release waiter on cancellation
            Task { await self.cancelWaiters() }
        }
    }

    private func cancelWaiters() {
        // Resume all with cancellation
    }

    deinit {
        // In actor deinit, waiters are already released
        // But if using class: must resume all
    }
}
```

Ensure withTaskCancellationHandler wraps continuation storage.

<task type="auto">
  <name>Task 2: Simplify ResponseTransformation continuations</name>
  <files>Sources/Networking/ResponseTransformation.swift</files>
  <action>
Current pattern has nested Task inside continuation - complex and risky.

Simplify to pure async:
```swift
// BEFORE (risky):
func transform(_ data: Data) async throws -> T {
    try await withCheckedThrowingContinuation { continuation in
        Task {
            do {
                let result = try decode(data)
                continuation.resume(returning: result)
            } catch {
                continuation.resume(throwing: error)
            }
        }
    }
}

// AFTER (simple):
func transform(_ data: Data) async throws -> T {
    // Just do the work directly - we're already async
    return try decode(data)
}
```

If truly needs continuation (e.g., wrapping callback-based API):
```swift
func transform(_ data: Data) async throws -> T {
    try await withCheckedThrowingContinuation { continuation in
        // Only ONE path to resume
        callbackBasedAPI(data) { result in
            switch result {
            case .success(let value):
                continuation.resume(returning: value)
            case .failure(let error):
                continuation.resume(throwing: error)
            }
        }
    }
}
```

Remove nested Task patterns entirely.
