Create MockBearerTokenProvider.swift implementing BearerTokenProvider and MockVerifiable:

1. Class structure (following MockNetworkClient pattern):
   - `public final class MockBearerTokenProvider: BearerTokenProvider, MockVerifiable, @unchecked Sendable`
   - Private DispatchQueue for thread safety: `private let queue = DispatchQueue(label: "mock.token.provider", attributes: .concurrent)`

2. State tracking (queue-protected):
   - `private var stubbedToken: String?`
   - `private var stubbedRefreshToken: String?`
   - `private var tokenFetchCount: Int = 0`
   - `private var refreshCount: Int = 0`

3. Protocol conformance - BearerTokenProvider:
   - `func getCurrentToken() async throws -> String?` - Returns stubbedToken, increments tokenFetchCount
   - `func refreshToken() async throws -> String` - Returns stubbedRefreshToken or throws, increments refreshCount

4. Stubbing methods:
   - `func stubToken(_ token: String)` - Sets stubbedToken (barrier write)
   - `func stubRefreshToken(_ token: String)` - Sets stubbedRefreshToken (barrier write)
   - `func stubTokenFetchError(_ error: Error)` - Sets error to throw (barrier write)

5. MockVerifiable conformance:
   - `public var callCount: Int` - Returns tokenFetchCount + refreshCount (sync read)

6. Additional verification:
   - `func verifyTokenFetched(times: Int = 1) throws`
   - `func verifyRefreshed(times: Int = 1) throws`

7. Add @unchecked Sendable justification comment (same pattern as MockNetworkClient).
