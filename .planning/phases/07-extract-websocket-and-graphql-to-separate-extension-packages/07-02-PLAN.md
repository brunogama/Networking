  <action>
    Create the NetworkingWebSocket package structure with its own Package.swift:

    1. **Create directory structure**:
       ```bash
       mkdir -p Packages/NetworkingWebSocket/Sources/NetworkingWebSocket
       mkdir -p Packages/NetworkingWebSocket/Tests/NetworkingWebSocketTests
       ```

    2. **Create Package.swift for NetworkingWebSocket**:
       ```swift
       // swift-tools-version: 6.0
       // NetworkingWebSocket - WebSocket extension for Networking

       import PackageDescription

       let package = Package(
         name: "NetworkingWebSocket",
         platforms: [
           .iOS(.v16),
           .macOS(.v13),
           .tvOS(.v16),
           .watchOS(.v9),
         ],
         products: [
           .library(
             name: "NetworkingWebSocket",
             targets: ["NetworkingWebSocket"]
           )
         ],
         dependencies: [
           // Local dependency on Core Networking package
           .package(path: "../Networking"),
         ],
         targets: [
           .target(
             name: "NetworkingWebSocket",
             dependencies: [
               .product(name: "Networking", package: "Networking"),
             ],
             swiftSettings: [
               .unsafeFlags(["-warn-concurrency", "-enable-actor-data-race-checks"])
             ]
           ),
           .testTarget(
             name: "NetworkingWebSocketTests",
             dependencies: ["NetworkingWebSocket"]
           ),
         ]
       )
       ```

    **KEY ARCHITECTURE POINTS**:
    - Uses `.package(path: "../Networking")` for local dependency
    - Does NOT use root Package.swift - this is a completely independent package
    - Test target depends only on NetworkingWebSocket (which transitively provides Networking)
  </action>
  <verify>
    ```bash

    ls -la Packages/NetworkingWebSocket/Tests/
    ```
