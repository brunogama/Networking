# Phase 10.2.1 Plan 01: Restore @API and @Body Macro Tests

**One-liner**: APIMacroTests (5 tests) and BodyMacroTests (7 tests) restored using MacroTesting framework, validating protocol-to-client generation and body parameter marker behavior.

## What Was Built

Restored two fundamental macro test files using MacroTesting framework:

1. **APIMacroTests.swift** - Protocol-to-client generation validation
   - 2 expansion tests: basic protocol, complex protocol name
   - 3 diagnostic tests: requires protocol, requires baseURL, empty baseURL validation

2. **BodyMacroTests.swift** - Request body marker macro validation
   - 3 expansion tests: basic usage, multiple parameters, external/internal names
   - 4 diagnostic tests: parameter not found, missing argument, non-function, multiple macros

## Implementation Details

### Task 1: APIMacroTests Restoration

**Pattern followed**: GETMacroTests.swift using MacroTesting framework

**Key test cases**:
- `testAPIBasicExpansion()`: Validates `@API(baseURL: "...")` generates struct with client, baseURL, init
- `testAPIWithComplexProtocolName()`: Validates protocol name → Implementation suffix transformation
- `testAPIRequiresProtocol()`: Validates @API only applies to protocols (not structs)
- `testAPIRequiresBaseURL()`: Validates baseURL argument is required
- `testAPIEmptyBaseURL()`: Validates baseURL cannot be empty string

**Implementation notes**:
- APIMacro generates struct WITHOUT Sendable conformance in output (renderer behavior)
- Expected expansion adjusted to match actual macro output (no blank line after baseURL property)

### Task 2: BodyMacroTests Restoration

**Pattern followed**: GETMacroTests.swift using MacroTesting framework

**Key test cases**:
- `testBodyMacroBasicUsage()`: Validates marker macro returns empty (no peer code)
- `testBodyMacroWithMultipleParameters()`: Validates multi-param function support
- `testBodyMacroWithInternalParameterName()`: Validates external/internal parameter names
- `testBodyMacroParameterNotFound()`: Validates parameter existence in function signature
- `testBodyMacroWithoutArgument()`: Validates argument requirement
- `testBodyMacroOnNonFunction()`: Validates function-only restriction
- `testBodyMacroMultipleOnSameFunction()`: Validates single-macro constraint

**Implementation notes**:
- BodyMacro is a PeerMacro that returns empty array (marker pattern)
- MacroExpansionError wraps messages as "Invalid path template" for some error types
- bodyParameterNotFound error message: "Body parameter 'X' not found in function signature. Available: [...]"
