# Agents

Store sub-agent findings, handoff notes, and synthesized outputs here when parallel work is
running.

## Suggested Pattern

- one file per subtask or agent
- include objective, files touched, findings, and unresolved questions
- keep the handoff richer than chat summaries so the coordinator can read the source directly

Recommended names:

- `networking-runtime-review.md`
- `macro-validation-handoff.md`
- `bdd-migration-findings.md`
