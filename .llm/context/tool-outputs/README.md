# Tool Outputs

Use this directory for large command output that should not live in chat.

## What Belongs Here

- `swift build` logs
- `swift test` logs
- long `git diff` or search output snapshots
- lint output
- research dumps or copied diagnostics

## Naming Convention

Use: `YYYYMMDD-topic-command.txt`

Examples for the current repo state:

- `20260310-networking-build.txt`
- `20260310-networking-test.txt`
- `20260310-networkingmacros-build.txt`
- `20260310-networkingmacros-test.txt`

Keep a short summary of each artifact in `session-summary.md` instead of repeating the full output.
